## 3. O ambiente, medido hoje

- **`git push` daqui continua recusado** pelo classificador («Out-of-Place Publication») — o push é do dono
  (`! git -C /opt/financeiro/app push origin main`). **`gh workflow run deploy-financeiro.yml` passou daqui.**
- **Depois do push do dono (como root), `.git/refs/remotes/origin/main` fica com dono root** — `chown` desse
  arquivo antes do deploy (o `chown` de arquivo único passou).
- **Worktree novo** (`runuser -u financeiro -- git worktree add …`) precisa de quatro symlinks: `node_modules`,
  `web/node_modules`, `src/generated` e `spike-transacao/generated` — os dois últimos entraram no
  `.git/info/exclude` em 14/10. Sem o último, o `npm run typecheck` da raiz falha.
- **Git como root no worktree** reescreve `.git/worktrees/<wt>/index` como root, e o hook do Impeccable cria
  `.git/worktrees/<wt>/info/exclude` como root: git sempre via `runuser -u financeiro`, e `find … -user root`
  antes do commit.
